# Agent instructions

Everyday work starts from current `dev` on a short-lived branch and reaches `dev` through a pull request. Release pull requests alone target `main`, and releases are tagged on `main` as `vMAJOR.MINOR.PATCH`. See [CONTRIBUTING.md](CONTRIBUTING.md).

The product specification is [docs/spec.md](docs/spec.md). This repository is public: never commit credentials, customer data or nursery records.

Words on screen are whole, natural sentences in plain UK English, and every action is a styled button: see "Words on screen" and "Buttons and links" in [CONTRIBUTING.md](CONTRIBUTING.md).
